# 맞춤 제작 가방 — 스마트스토어 CTR · CTA · SEO 전략

> 상품을 등록하기 전에 정하는 기준입니다. `products/products.json`의 문구와 설정은 모두 이 문서를 따릅니다.

## 0. 핵심 가설

맞춤 제작 가방은 **"검색에서 발견 → 대표이미지·상품명으로 클릭 → 옵션으로 '내 가방'을 상상 → 구매 또는 상담"** 순서로 전환됩니다.
그래서 이렇게 나눠서 운영합니다.

- **검색(SEO)은 '도안(디자인)'별 상품으로 받습니다.** 사람들은 "맞춤 가방"보다 "캔버스 토트백", "이니셜 가방"처럼 형태와 용도로 검색합니다.
- **클릭(CTR)은 '완성품 사진'으로 받습니다.** 대표이미지에서 도안 자체가 보여야 합니다.
- **전환(CTA)은 '맞춤 제작'으로 만듭니다.** 상품명, 옵션, 상세 첫 화면에서 반복해 알립니다.

---

## 1. SEO — 네이버 쇼핑 검색 노출

네이버 쇼핑 랭킹은 **적합도(상품명·카테고리·속성·태그) + 인기도(클릭·판매·리뷰·찜) + 신뢰도(어뷰징 여부)**로 정해집니다. 등록 단계에서 바꿀 수 있는 것은 **적합도**입니다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 상품명 | **50자 이내**. `브랜드 + 핵심키워드(형태) + 속성(소재·기능) + 맞춤 키워드 + 용도`. 같은 단어는 한 번만 | 중복 키워드와 과한 길이는 어뷰징 감점 대상입니다 |
| 금지어 | 상품명에 `최저가`, `무료배송`, `할인`, `특가`, `1+1`, 특수문자(★, ♥, [ ] 남용)를 넣지 않습니다 | 네이버 상품명 가이드 위반으로 노출이 떨어집니다 |
| 카테고리 | 패션잡화 > 여성가방/남성가방 > **형태별 세부 카테고리**(토트백·크로스백·에코백)로 정확히 지정합니다 | 카테고리가 틀리면 해당 키워드 검색에서 거의 노출되지 않습니다 |
| 속성 | 소재, 색상, 사이즈, 수납, 여밈 방식 등 **보이는 속성을 전부 입력**합니다 | 검색 필터(소재: 캔버스 등)에 걸려야 노출됩니다 |
| 태그 | **최대 10개**. 네이버 태그 사전에 있는 키워드(자동완성에 뜨는 것)를 우선 씁니다. 상품명에 없는 **용도·타깃·상황 키워드**를 넣습니다 | 상품명에 쓰지 못한 롱테일 키워드를 태그로 보완합니다 |
| 브랜드·제조사·모델명 | 브랜드명은 항상 같은 표기로 입력하고, 모델명은 도안 코드로 씁니다(예: `DOAN-T01`) | 브랜드 검색 노출과 카탈로그 매칭에 쓰입니다 |
| 상세설명 | 이미지만 넣지 말고 **텍스트 블록**(소재, 사이즈, 맞춤 가능 항목)을 함께 넣습니다 | 텍스트로 된 상세설명도 검색 적합도에 반영됩니다 |
| 원산지·제작 | 국내 제작이면 원산지를 "국산"으로 정확히 입력합니다 | 필수 항목이고 신뢰도에 영향을 줍니다 |

**키워드 설계 방식**(각 도안마다):
1. **메인 키워드 1개:** 검색량이 큰 형태 키워드(예: `토트백`)
2. **서브 키워드 2~3개:** 소재·기능(예: `캔버스`, `이니셜 각인`)
3. **맞춤 키워드 1개:** `맞춤제작` 또는 `주문제작` 중 하나만
4. **용도 키워드는 태그로:** `출근가방`, `선물용가방`, `커플가방` 등

> 실제 등록 전에 **네이버 광고 > 키워드 도구**에서 월간 검색수와 경쟁정도를 확인하고, 메인·서브 키워드를 최종 확정하세요.

## 2. CTR — 검색 결과에서 클릭받기

검색 결과 화면에서 고객이 보는 것은 **대표이미지, 상품명 앞 15자, 가격, 리뷰 수, 배송 정보**뿐입니다.

1. **대표이미지**
   - 1000×1000px 이상의 정사각형입니다. 흰색이나 연한 단색 배경에 **완성품 한 개**가 화면의 70~80%를 차지하게 찍습니다.
   - 대표이미지에 **텍스트, 워터마크, 테두리를 넣지 마세요.** 네이버 이미지 가이드 위반으로 노출이 떨어집니다. "맞춤 제작" 문구는 추가이미지와 상세페이지에서 알립니다.
   - **각인·이니셜이 보이는 컷**을 대표로 쓰면 목록에서 바로 "맞춤이 되는 가방"으로 인식됩니다. (텍스트 오버레이가 아니라 실제 제품에 새긴 각인이면 괜찮습니다.)
2. **추가이미지(최대 9장) 순서**
   - ① 착용컷 → ② 색상 조합 모음 → ③ 각인·이니셜 클로즈업 → ④ 사이즈 비교 → ⑤ 내부 수납 → ⑥ 제작 과정 → ⑦ 포장
3. **상품명 앞 15자에 형태와 맞춤을 모두 넣습니다.** 목록에서 잘려도 `맞춤제작 캔버스 토트백`이 보이게 합니다.
4. **가격:** 기본 도안 가격은 낮게 보이도록 **기본가 + 추가옵션(각인·원단 업그레이드)** 구조로 설정합니다. 목록에는 기본가가 노출됩니다.
5. **초기 인기도 확보:** 첫 리뷰 이벤트(포토리뷰 적립금)와 알림받기 쿠폰을 켭니다. 리뷰 수는 CTR에 직접 영향을 줍니다.

## 3. CTA — 상세페이지에서 구매·상담으로 넘기기

맞춤 제작 상품의 가장 큰 이탈 이유는 **"어떻게 주문하지?"와 "언제 받지?"**라는 불확실성입니다. 그래서 CTA는 두 갈래로 만듭니다.

```
[경로 A] 바로 구매 — 옵션으로 해결되는 맞춤 (색상 / 끈 / 각인 문구)
[경로 B] 톡톡 상담 — 옵션으로 안 되는 맞춤 (사이즈 변경 / 로고 / 단체 주문)
```

**상세페이지 구성**(첫 화면에서 바로 결론을 보여줍니다):
1. **Hero:** "세상에 하나뿐인 내 가방 — 도안을 고르고, 색과 이름을 정하세요"
2. **맞춤 가능 항목 3가지**(아이콘과 함께): 원단 색상 / 끈 색상 / 이니셜 각인
3. **주문 3단계:** ① 도안 선택 → ② 옵션에서 색상·각인 입력 → ③ 제작 후 발송(소요일 명시)
4. **CTA 버튼 문구**
   - "지금 옵션에서 내 가방 만들기 ↓"
   - "사이즈·로고 변경은 톡톡으로 문의하세요 → 24시간 내 시안 회신"
5. 도안 상세, 소재, 사이즈표
6. 제작 과정 사진(신뢰 요소)
7. 리뷰와 착용컷
8. 반복 CTA와 교환·환불 안내

**옵션 설계**(스마트스토어 기능):
- **조합형 옵션:** `원단 색상` × `끈 색상`
- **직접입력형 옵션:** `각인 문구(영문 10자 이내)`
- **추가상품:** `각인 추가(+금액)`, `선물 포장(+금액)`

## 4. 필수 설정 — 맞춤 제작 상품이라서 꼭 해야 하는 것

- **배송 > 배송 속성:** `주문 확인 후 제작`을 선택하고 **발송 소요일**(예: 7일)을 입력합니다. 일반배송으로 두면 발송 지연 페널티를 받습니다.
- **청약철회(교환·반품) 제한 고지:** 개별 주문에 따라 제작하는 상품은 전자상거래법 제17조 제2항 제6호에 따라 단순변심 반품을 제한할 수 있습니다. 다만 **구매 전에 고지하고 동의를 받아야** 합니다. 상세페이지와 반품 안내에 명시하세요.
- **상품정보제공고시:** 가방 카테고리 항목(종류, 소재, 색상, 크기, 제조자, 제조국, 취급 시 주의사항, 품질보증기준, A/S 연락처)을 모두 입력합니다.
